AI-Powered ChatGPT Clone

Developer: Ashenafi Elias
Purpose: Evangadi Forum AI Certification & Portfolio Project

A full-stack AI chatbot inspired by ChatGPT, built with React, Vite, Node.js, Express, and MySQL. It integrates Google Gemini AI for conversational responses and JWT authentication for secure user access.

Tech Stack

Frontend: React, Vite, JavaScript

Backend: Node.js, Express.js

Database: MySQL

AI: Google Gemini API

Authentication: JWT

Deployment: Vercel and Render

Key Features

AI-powered conversations

User registration and login

User-specific chat history

REST API integration

Secure environment configuration

Setup

Configure MySQL using backend/db/schema.sql.

Copy .env.example files and add your own credentials.

Run npm install and npm run dev in both backend/ and frontend/.

Security

Never commit .env files or expose API keys, database credentials, or JWT secrets.

Project Goal

Demonstrate my skills in full-stack development, AI integration, authentication, database management, and application deployment.
